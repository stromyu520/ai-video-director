# 🎬 智能剪辑项目文档

## 项目概览

AI 驱动的全自动视频生成管线。输入一个标题或想法，AI 执行搜索素材 → 写稿 → 分析情感节奏 → 语音克隆合成 → 画面组装 → BGM 混音 → 字幕，全流程自动化。

**核心架构：AI 导演模式**

```
用户（标题/URL/素材）
    ↓
┌─ Hermes Agent (AI 导演) ──────────────────┐
│  联网搜索 → 内容分析 → 写解说稿            │
│  定情绪节奏 → 配画面/BGM 方案              │
│  输出 director.yaml                        │
└────────────────────────────────────────────┘
    ↓ 用户确认
┌─ video_make_ffmpeg.py (执行层) ────────────┐
│  tts_express.py → 带情感的语音合成          │
│  场景逐段渲染 → concat 拼接                 │
│  SRT 字幕生成 → 字幕叠加                     │
│  BGM 混音 → 输出 MP4                        │
└────────────────────────────────────────────┘
```

## 核心组件

### 1️⃣ tts_express.py — 智能表现力 TTS

**定位**：AI 驱动的语音合成引擎。读文本 → 理解情感/语气 → 自动插入呼吸/叹气/笑声等表现力标记 → CosyVoice 3 合成带情绪的人声。

**工作流**：

```
输入文本                   参考音频/视频
    ↓                          ↓
LLM 理解语义             ffmpeg 提取/转码
(DeepSeek API)           whisper 找最佳 3-5 秒
    ↓                          ↓
插入 [breath] [sigh]    24000Hz 单声道
[laughter] <strong>
    ↓                          ↓
    └────→ CosyVoice 3 合成 ←────┘
              ↓
       带呼吸/叹气/笑声/
       情绪/语速的人声
```

**用法**：

```bash
# 基础克隆（无情感）
video-env python tts_express.py "你好，欢迎收听。" demo.mp4

# 情感表现模式（一键开启）
video-env python tts_express.py "他叹了口气说：我认输。" ref.wav --express

# 用已注册音色 + 情感表现
video-env python tts_express.py "你竟然骗了我！" --spk-id 故事女声 --express --speed 快

# 方言控制（17种方言）
video-env python tts_express.py "今天天气真好" ref.wav --express --lang 四川话
```

**参数一览**：

| 参数 | 作用 |
|------|------|
| `text` | 要合成的文本 |
| `ref_audio` | 参考音频/视频（自动预处理、找最佳片段） |
| `--spk-id` | 使用已注册音色（替代 ref_audio） |
| `--express` | **一键开启情感表现**（LLM 自动分析+标记） |
| `--speed` | 语速：`快` / `慢`（需配合 `--express`） |
| `--lang` | 方言：广东话/四川话/东北话等17种（需 `--express`） |
| `--text-file` | 从文件读取长文本 |
| `--output` | 输出路径（默认 output.wav） |

**表现力标记清单**（定义在 `tts_express_prompt.md`）：

| 标记 | 效果 |
|------|------|
| `[breath]` | 呼吸声 |
| `[quick_breath]` | 快速呼吸（紧张/急促） |
| `[sigh]` | 叹气（无奈/失望/放松） |
| `[laughter]` | 笑声（好笑/自嘲） |
| `[cough]` | 咳嗽（尴尬/清嗓） |
| `[lipsmack]` | 咂嘴（犹豫/思考） |
| `[clucking]` | 啧声（不满/惋惜） |
| `[hissing]` | 嘶声/倒吸冷气（惊讶/震惊） |
| `[mn]` | 嗯声（思考/应答） |
| `<strong></strong>` | 强调语气 / 重音 |

**LLM 回退机制**：无网络时自动降级为启发式规则加标记（基于标点和关键词匹配）。

### 2️⃣ voice_cli.py — 音色注册与管理

**定位**：注册发音人音色到模型，后续合成时直接通过 spk-id 引用，无需重复提供参考音频。

**用法**：

```bash
# 注册音色（只需一次）
video-env python voice_cli.py 注册 <参考音频/视频> "视频里说的话"

# 用已注册音色合成
video-env python voice_cli.py 合成 "要生成的文本"
```

**示例**：

```bash
# 注册
video-env python voice_cli.py 注册 zero_shot_prompt.wav "希望你以后做得比我还好"

# 合成
video-env python voice_cli.py 合成 "你好，我是故事女声，欢迎收听今天的故事。"
```

**已注册音色**：

- **故事女声** — 基于官方 `zero_shot_prompt.wav`

**音色存储**：`models/Fun-CosyVoice3-0-5B-2512/spk2info.pt`（可用环境变量 `COSYVOICE_MODEL` 改）
（删除该文件即清除所有已注册音色）

### 3️⃣ bgm_prep.py — BGM 预处理

**定位**：从视频/音频中提取 BGM，支持人声分离（Demucs）、裁剪、循环交叉淡化、音量标准化。

**原理**：抖音短视频全程 BGM + 人声重叠 → Demucs 4-stems 分离
- `drums + bass + other` = 纯 BGM
- `vocals` = 人声

**用法**：

```bash
# 提取音频（自动规范化）
video-env python bgm_prep.py 音乐.mp3 --output BGM/轻快.wav

# 从短视频提取纯BGM（人声分离）
video-env python bgm_prep.py 抖音视频.mp4 --separate --output BGM/纯音乐.wav

# 裁剪片段 + 循环至指定时长
video-env python bgm_prep.py 音乐.mp3 --start 10 --end 30 --loop-to 60

# 提取 + 分离 + 循环
video-env python bgm_prep.py 抖音视频.mp4 --separate --start 5 --end 25 --loop-to 90
```

**参数**：

| 参数 | 作用 |
|------|------|
| `input` | 源文件（音频或视频） |
| `--output / -o` | 输出路径 |
| `--start` | 裁剪起始秒数 |
| `--end` | 裁剪结束秒数 |
| `--loop-to` | 循环至目标时长（秒） |
| `--separate` | 人声分离（Demucs），提取纯 BGM |
| `--fade-in` | 淡入秒数（默认 2s） |
| `--fade-out` | 淡出秒数（默认 3s） |

### 4️⃣ video_make_ffmpeg.py — 视频组装引擎（主力）

**定位**：读 `director.yaml` → 全场景 TTS 合成 → 素材准备（图片/本地视频/Pexels 自动下载）→ 镜头化渲染 → xfade 交叉溶解拼接 → 全局 ASS 字幕 + BGM 混音终稿 → 输出 MP4。使用 **ffmpeg** 处理，比 moviepy 快约 10 倍。

**用法**：

```bash
video-env python video_make_ffmpeg.py <director.yaml>
```

**工作流**：

```
director.yaml
    ↓
┌─ Phase 2: 镜头化管线 ─────────────────────────┐
│  1. 全部场景 tts_express.py → 合成语音         │
│  2. 素材准备：                                   │
│     图片 → 缩放裁剪至 1920×1080                 │
│     "搜索:关键词" → Pexels 自动搜索下载视频      │
│     本地视频 → 直用（crop 铺满）                 │
│     无素材 → 文字卡片兜底                        │
│  3. 镜头化：视频场景拆 ≤5s 镜头，图片 Ken Burns  │
│  4. 逐镜头渲染（无音轨）                        │
│  5. xfade 0.16s 交叉溶解拼接（三步法，           │
│     失败自动回退 concat 硬切）                  │
│  6. 全局 ASS 字幕 + BGM 混音单 pass 终稿        │
└────────────────────────────────────────────────┘
    ↓
✅ output.mp4
```

**特性**：

- **动态素材**：`visuals.source: "搜索:城市夜景"` 自动从 Pexels 下载高清视频素材（24h 搜索缓存 + URL 去重，见 `pexels_materials.py`）
- **手动素材**：把视频放进项目目录 `素材/` 子目录，场景 `visuals: {type: "video"}`（或 source 留空）即自动发现并按场景顺序分配；多镜头同素材时按时间段精确切片，画面不重复
- **图片**：自动缩放裁剪至 1920×1080 + Ken Burns 慢推（输入放大 4K 再 zoompan + bicubic 插值，推镜丝滑无抖动）
- **转场**：所有镜头间 0.16s 交叉溶解（帧量化），替代原硬切
- **节奏**：视频场景按旁白时长拆 ≤5s 镜头（对齐短视频节奏），素材短于镜头自动循环
- **字幕**：全局 ASS 烧录，60px 大字 + 圆角半透明背景（55% 不透明），whisper 词级时间戳精确同步（失败回退按字数比例分配）
- **文字卡片**：深色背景 + mood 大字（旁白由全局字幕承担，不再重复绘制小字）
- **BGM**：全局音量控制，淡入/淡出（`normalize=0` 防音量塌缩）
- **spoken 字段**：TTS 朗读用"spoken"文本（数字转中文防读错），字幕用"narration"保持可读性

## director.yaml 完整参考

`director.yaml` 是整个管线中 AI 导演的输出格式和执行层的输入标准。

```yaml
# ============================================================
# director.yaml — AI 导演剪辑方案
# Hermes Agent 生成 → 脚本执行
# ============================================================

# ---------- 项目信息 ----------
project:
  title: "视频标题"           # 视频标题（显示用）
  duration: 60                # 目标时长（秒）
  type: "新闻"                # 新闻 / 二创 / 解说

# ---------- 声音配置 ----------
voice:
  spk_id: "故事女声"          # 音色ID
  express: true               # 是否开启情感表现
  speed: "中"                 # 全局语速基调（快/中/慢）

# ---------- 场景列表（核心） ----------
scenes:
  - id: 1
    start: 0                  # 起始时间（秒，用于参考）
    duration: 8               # 场景时长（秒）
    narration: "你可能不知道，就在昨天..."  # 字幕用文本（正常数字）
    spoken: "你可能不知道，就在昨天..."      # 可选，TTS用（数字转中文防读错）
    mood: "悬念"              # 情绪：悬念/平实/兴奋/沉重/搞笑/高潮/收尾
    speed: "慢"               # 本段语速（覆盖全局）
    visuals:
      type: "image"           # image / text / video（可留空自动判断）
      source: "图片/主视觉.jpg" # 图片路径 / "搜索:关键词"（Pexels 自动下载）
                              # 或本地视频路径；留空 → 自动使用 素材/ 目录的视频
    bgm:                      # 可选，覆盖全局BGM
      volume: 0.3

  - # ...更多场景...

# ---------- 背景音乐 ----------
bgm:
  path: ""                    # BGM文件路径（留空则不使用）
  volume: 0.25                # 全局BGM音量
  fade_in: 2                  # 淡入秒数
  fade_out: 3                 # 淡出秒数

# ---------- 输出设置 ----------
output:
  path: ""                    # 输出文件路径（留空自动生成）
  subtitle: true              # 是否加字幕
  subtitle_style: "底部居中，白色描边"  # 字幕样式描述
```

**mood 情绪配色方案**：

| 情绪 | 背景色 | 说明 |
|------|--------|------|
| 悬念 | `#1a1a3e` | 深蓝紫 |
| 兴奋 | `#1a3e1a` | 墨绿 |
| 高潮 | `#3e1a1a` | 暗红 |
| 搞笑 | `#2e2e1a` | 暖黄 |
| 沉重 | `#1a1a1a` | 纯黑 |
| 收尾 | `#1a1a2e` | 深蓝 |
| 平实 | `#0f0f23` | 深靛蓝（默认） |

## 三条管线详解

### 📰 新闻管线（新闻/）

**用途**：从新闻标题或 URL 自动生成资讯短视频。

**流程**：

```
用户给新闻标题
    ↓
Hermes Agent:
├── 联网搜索 → 获取新闻详情
├── 分析重点 → 定节奏（悬念→兴奋→高潮→收尾）
├── 搜索配图 → 下载
├── 写解说稿 → 按场景分段
└── 生成 director.yaml
    ↓ 用户确认
video_make_ffmpeg.py director.yaml → output.mp4
```

**适用场景**：国际新闻、科技快讯、财经简报、AI 头条、趣闻杂谈

### 🎬 二创管线（二创/）

**用途**：对原始视频素材进行二次创作（智能剪辑）。本质 = 原视频裁剪片段 + 新素材 + 字幕 + 新声音 → 重新生成新视频。

**流程**：

```
原始视频 + 创意方向
    ↓
analyze_video.py → analysis.json（镜头检测 + 转录 + VLM 画面分析）
plan_remix.py → remix.yaml（DeepSeek 编排：original/image/clip/text 场景）
    ↓
render_remix.py → final_remix.mp4
```

**remix.yaml 场景类型**：

| 类型 | 含义 | 素材来源 |
|------|------|---------|
| `original` | 裁剪原视频片段（可非线性跳跃、保留原声 `audio: original`） | 原视频时间轴 |
| `image` | 插入图片 | 本地 `图片/` 目录 |
| `clip` | 插入短片 | `"搜索:关键词"`（Pexels 自动下载）/ `短片/`+`素材/` 目录自动发现 / 本地路径 |
| `text` | 收尾文字卡片 | — |

**素材来源优先级**：`搜索:关键词`（Pexels 下载）→ `短片/`、`素材/` 目录自动发现（按场景顺序轮转）→ yaml 精确路径。

**字幕**：非 original 场景烧录 ASS 圆角半透明背景字幕（60px 大字，`ass_subtitle.py`），与通用管线同款。

**命令**：

```bash
video-env python analyze_video.py <视频.mp4> [输出目录]      # → analysis.json
video-env python plan_remix.py <工作目录> [--bgm 音乐]        # → remix.yaml
video-env python render_remix.py <工作目录> [--bgm 音乐]      # → final_remix.mp4
```

### 🔗 通用剪辑管线（其他/）

**用途**：用户给标题或网页链接，自动搜索内容生成解说视频。

**流程**：

```
用户: 标题 / URL
    ↓
Hermes Agent:
├── 联网搜索 → 获取内容
├── 分析重点 → 定节奏/情绪
├── 搜索配图 → 下载到 图片/
├── 写解说稿 → 按场景分段
└── 生成 director.yaml
    ↓ 用户确认
video_make_ffmpeg.py director.yaml → output.mp4
```

**产出物结构**：

```
其他/项目名称/
├── director.yaml    ← 导演方案
├── 图片/            ← 配图
└── output.mp4       ← 成品视频
```

## 核心约定

| 项目 | 约定 |
|------|------|
| 视频尺寸 | 1920×1080 (16:9) |
| 音频参数 | 24000Hz / 单声道 / AAC 192kbps |
| 视频编码 | H.264 (libx264) |
| 中文字体 | 文泉驿正黑 (wqy-zenhei.ttc) |
| 字幕格式 | ASS（SRT 时间轴转换），60px 圆角半透明背景，底部居中 |
| 默认输出 | `output.wav`（TTS） / `output.mp4`（视频） |
| BGM 目录 | 手动放入 `BGM/` 目录，需预处理后再使用 |

**spoken 字段约定**：TTS 朗读用 `spoken` 文本（数字转中文防读错），视频字幕用 `narration` 保持可读性。例如：

```yaml
narration: "标致508L售价16.37万起"
spoken:    "标致五零八L售价十六万三千七起"
```

## LLM 配置

本地项目所有 LLM 调用走 OpenAI 兼容格式（requests 直接发 JSON），默认 DeepSeek。**思考模式设置已按任务类型调优**：

| 调用点 | 任务类型 | 思考模式 | 参数 |
|--------|---------|---------|------|
| `tts_express.py` 表现力标记 | 规则型（文本→插标记） | **关闭** | `"thinking": {"type": "disabled"}` |
| `check_materials.py` 素材评估 | 短输出评估 | **关闭** | `"thinking": {"type": "disabled"}` |
| `video_make_ffmpeg.py` 导演编排 | 创作/权衡（场景重排+文案） | **开启，effort=low** | `"reasoning_effort": "low"` |
| `plan_remix.py` 二创编排 | 同上 | **开启，effort=low** | `"reasoning_effort": "low"` |

**为什么这么配**（实测结论，2026-08）：
- 规则型任务关闭思考：质量不降（甚至更准），token 省 80%
- 编排任务**不要用默认 high**：DeepSeek 推理模型（deepseek-v4-flash）的思考 token 计入 `max_tokens`，高思考量会吃光预算导致 `content` 空输出（随机失败）；`effort=low` 稳定 + 省 92% token + 指令遵循度最好（disabled 会"放飞"：乱拆场景、重复引用图片）
- 若觉得 low 档编排质量不够，**优先优化 prompt**，不要升档

**环境变量**：

```bash
# LLM（默认 DeepSeek，可换任何 OpenAI 兼容端点）
LLM_API_URL=https://api.deepseek.com/v1/chat/completions
LLM_API_KEY=sk-xxx
LLM_MODEL=deepseek-v4-flash

# 换 k3（Moonshot，key 在 MPT config.toml 里现成）
LLM_API_URL=https://api.moonshot.cn/v1/chat/completions
LLM_API_KEY=<moonshot_api_key>
LLM_MODEL=kimi-k3
# 注意：k3 虽是多模态模型，但本地管线当前未接图像输入；
# 图片内容分析永远走本地 Qwen3.5-2B（LLM 只管排版）
# 路径在 config.toml 的 [vlm] model_dir，页面上可改；
# 只对「手动上传的图片」跑，见 video_make_ffmpeg.is_manual_image()
```

**Pexels 素材 key**（读取链，无需配置即可复用 MPT 的 key）：

```bash
PEXELS_API_KEY=xxx          # 环境变量 > config.toml [pexels] api_key > MPT config.toml
```

## 常⻅问题

**Q：TTS 合成效果不好？**
- 参考音频内容必须和参考文本**匹配**
- 合成文本建议 **20 字以上**
- `--express` 模式需要 DeepSeek API 联网

**Q：DeepSeek API 用不了？**
- 检查环境变量 `LLM_API_URL` / `LLM_API_KEY` / `LLM_MODEL`
- 无网络时自动降级为启发式规则

**Q：模型下载慢？**
- WSL2 无法直连 huggingface.co
- 设置 `HF_ENDPOINT=https://hf-mirror.com` 使用镜像
- 或用本地 `--repo` 路径

**Q：视频渲染慢？**
- 使用 `video_make_ffmpeg.py`（ffmpeg 版本）而非 moviepy 版本
- ffmpeg 版本使用硬件编码加速，速度提升约 10 倍
